# 백엔드 명세 (mirror)

이 디렉터리는 백엔드 팀이 작성한 명세 문서의 **사본**입니다.
원본은 Notion이며, 이 파일들을 직접 수정하지 마세요.
백엔드 설계가 바뀌면 Notion에서 다시 export 해서 통째로 교체합니다.

리포에 사본을 두는 이유는 프론트엔드 데이터 모델이 무엇을 근거로 만들어졌는지
코드 옆에서 확인할 수 있어야 하기 때문입니다.

| 파일 | 내용 |
| --- | --- |
| `api-spec.md` | 14개 엔드포인트, 공통 응답 형식, 코드값, Validation 규칙 |
| `erd.md` | 7개 테이블 관계, 복합 PK, CHECK 제약조건 |
| `data-tables.md` | 컬럼 단위 타입·길이·NULL 허용 여부 |
| `design-changes-2026-08-10.md` | 8/10 회의 이후 변경 배경 (`note` 제거, `emotions[]` 다중 선택, 태그 도입, 로그인 추가) |

기준 시각: 2026-08-12 export 본.

## 프론트엔드에서 대응되는 위치

- `src/api/types.ts` — 위 명세에서 파생한 요청·응답 타입과 코드값
- `src/adapters/types.ts` — 기기 감지 결과를 서버 전송 전까지 보관하는 `DetectedWalk`

## 읽을 때 주의할 점

- 세 테이블(`walk_candidates` → `experience_drafts` → `walk_experiences`)은
  각각 `1 : 0..1`로 이어지며, 하나로 합쳐진 레코드가 아닙니다.
- `note` 컬럼과 API 필드는 제거되었습니다. 되살리지 마세요.
- `suggestedTags`는 DB에 저장되지 않습니다. 사용자가 확인·수정한 `tags[]`만 저장됩니다.
- 걷기 감지·시작·종료 판단·로컬 알림은 전부 클라이언트 책임이며 서버 API가 없습니다.
- 걸음 수를 저장하는 컬럼은 어느 테이블에도 없습니다.
